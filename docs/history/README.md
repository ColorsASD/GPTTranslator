# Történeti dokumentáció

A GPTTranslator átnevezése előtti dokumentumok és mérési bizonyítékok a `pre-gpttranslator` pillanatképben szerepelnek. Az archívum a korábbi Gamer Translator kiadások tényleges programneveit, csomagútvonalait, EXE-neveit, release-URL-jeit és fájlhash-eit őrzi.

Ezek történeti adatok. A bennük szereplő elérési utak az ellenőrzéskori környezetet írják le; nem az aktuális GPTTranslator használati utasításai. A korábbi tesztszámok és sikeres ellenőrzések az ott rögzített forráshoz vagy EXE-hashhez tartoznak.

Az eredeti dokumentumok és az `evidence` fájlok bájtpontosan kerültek át az archívumba. A korábbi aláírási leírás relatív hivatkozásának megőrzéséhez az akkori `tools/sign_release.ps1` Git HEAD-változata is a pillanatkép része. Az [archívumjegyzék](archive-manifest.json) minden fájl SHA-256 értékét rögzíti.
